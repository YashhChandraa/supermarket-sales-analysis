# supermarket-sale-analysis

## Project Description

This project analyzes supermarket sales data using Python.

## Features

- Read sales dataset
- Check missing values
- Calculate total sales
- Calculate average sales
- Branch-wise sales
- Gender-wise sales
- Payment method analysis
- Generate charts

## Technologies Used

- Python
- Pandas
- Matplotlib

## Project Structure

```
data/
images/
src/
README.md
requirements.txt
```

## How to Run

Install libraries

```bash
pip install -r requirements.txt
```

Run Analysis

```bash
python src/analysis.py
```

Run Visualization

```bash
python src/visualization.py
```
